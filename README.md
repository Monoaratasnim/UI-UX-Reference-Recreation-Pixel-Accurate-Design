# Pixel-Perfect UI/UX Reference Recreation

A high-fidelity, pixel-consistent recreation of 7 distinctive UI/UX reference designs collected from Pinterest and design inspiration platforms. Built with a strong emphasis on layout precision, color accuracy, typography hierarchy, responsive behavior, and smooth motion using Framer Motion.

Live Deployment: [https://ui-ux-reference-recreation-pixel-ac.vercel.app](https://ui-ux-reference-recreation-pixel-ac.vercel.app)

---

## 🛠️ Tech Stack & Tools

* **Framework:** React , Vite
* **Styling:** Tailwind CSS (for modern, responsive layout control and precise color matching)
* **Animations:** Framer Motion (for fluid page transitions and interactive elements)
* **Icons:** Lucide React & React Icons (`lucide-react`, `react-icons`)

---

## 📱 Recreated Screens & Routes

Every screen has been developed to be fully responsive, working seamlessly across both mobile and desktop layouts as required by the assignment guidelines.

| Screen Name | Route Path | Description |
| :--- | :--- | :--- |
| **1. Ride-Share Trip Details** | `/ride-trip-details` | Detailed mobile ride summary interface with route tracking cards and status indicators. |
| **2. Art Showcase Landing** | `/art-showcase` | Creative portfolio showcase featuring gallery grids, typography hierarchy, and curated imagery. |
| **3. Travel App Landing** | `/travel-landing` | Destination discovery landing page with search widgets, cards, and smooth hover animations. |
| **4. Finance Dashboard Landing**| `/finance-landing` | Clean financial analytics dashboard with metric cards, charts, and transaction history. |
| **5. Real Estate Investment Landing** | `/real-estate-landing` | Property investment platform highlighting listings, statistics, and call-to-action sections. |
| **6. Pricing Plans** | `/pricing-plans` | Subscription tier matrix with feature checklists, billing toggles, and highlighted popular plans. |
| **7. Developer Portfolio Landing** | `/developer-portfolio` | Modern developer landing page featuring interactive mockups, tech logos, and custom navigation drawers (`Stage` portfolio template). |
